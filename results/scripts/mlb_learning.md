# MLB script-then-learn: learning report

Generated by `python -m engine.scripts.mlb` (5.5 min). Games 2010-2026 run sequentially (2010-2015 warm-up), reported 2016+. Script = runs per side from the shared core (count model) + learned starting-pitcher and park Kalman effects + an online RLS correction on pre-game features. Win probability from `simulate_scores(count_model=True)` (ties = extra innings, 52% home), then an online logistic calibration; blend = online logistic of script and de-vigged closing moneyline. Market total = closing total line. Tuning (grid below) used only 2016-2020.

Data notes: 2010-2025 closing lines from data/processed/mlb.csv; 2026 results from data/live/mlb.csv with closing lines only for Sep 14-Oct 14 2026 (210 games), starters for 2026 taken from Statcast. Statcast pitcher-game data (K, BF, CSW) coverage by season:
