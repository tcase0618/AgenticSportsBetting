# MLB game predictor: winner + final score

Generated by `python -m engine.predict.mlb` (11.5 min). Strict walk-forward: every month from 2018 the models are refit on all games dated before that month (2016 onward) and predict the month. Model picked on 2018-2020 log loss; numbers reported for 2021+ (14,790 games) were never used to pick anything.

* Seasons 2016-2026 (2026 results from the live feed; closing prices only for Sep 14-Oct 14 2026, 210 games).
* Integrity note (results/KEYS.md): MLB 2021+ 'closing' prices failed a steam-move integrity check, so they may be closer to openers / stale quotes than true closes. They are still a pre-game number, so they are used as a feature after odds-ratio de-vig; clearly broken quotes are dropped (rule below). The model-vs-market comparison for 2021+ is against these prices.
* Run line: data has the ±1.5 side but no run-line prices, so break-even uses typical prices (-1.5 at +140, +1.5 at -160).
* Market: closing moneyline de-vigged with `engine.devig.devig(a, b, 'odds_ratio')`. Quotes dropped as broken: missing, |odds|<100, overround outside 0.995-1.12, de-vigged price outside the sport's plausible range or >30 pts away from the script (36 dropped by the last two rules in the predicted seasons). Games without a usable price fall back to the script (flag `has_mkt`=0).

## 5. The formula (plain English)

Win model **market**. Logistic part (full-data fit), intercept -0.071; terms per one standard deviation and per raw unit:

| feature      |   coef_per_SD |   coef_raw_unit |     SD |
|:-------------|--------------:|----------------:|-------:|
| sim_logit    |        0.2222 |          0.4446 | 0.4998 |
| mkt_gap      |        0.1227 |          0.6152 | 0.1995 |
| rls_home     |       -0.0916 |         -0.3291 | 0.2783 |
| mkt_logit    |        0.0828 |          0.2019 | 0.4101 |
| rls_away     |        0.0777 |          0.2762 | 0.2812 |
| a_opp_sp_k   |        0.0580 |          0.1796 | 0.3233 |
| h_opp_sp_k   |       -0.0575 |         -0.1787 | 0.3215 |
| s_logit      |        0.0548 |          0.1554 | 0.3529 |
| sp_away_ln   |        0.0442 |          0.0325 | 1.3584 |
| core_diff    |        0.0330 |          0.0485 | 0.6792 |
| a_opp_sp_new |       -0.0293 |         -0.1354 | 0.2167 |
| playoff      |       -0.0266 |         -0.2058 | 0.1291 |
| h_opp_sp_sc  |       -0.0251 |         -0.1126 | 0.2226 |
| margin       |       -0.0237 |         -0.0253 | 0.9365 |

In words: logit P(home wins) ≈ +0.445×sim_logit + +0.615×mkt_gap + -0.329×rls_home + +0.202×mkt_logit + +0.276×rls_away + (smaller terms) -0.071. `mkt_logit` = log-odds of the de-vigged closing moneyline, `s_logit` = script log-odds.

Score means (Poisson GLM, log link): log E[home runs] and log E[away runs] = intercept + Σ coef×feature, largest terms:

| s_logit        |             0.0427 |            -0.1385 |          0.1210 |
| mkt_gap        |             0.0590 |            -0.0963 |          0.2956 |
| margin         |            -0.0457 |             0.1026 |         -0.0488 |

| rls_home       |            -0.0335 |             0.0255 |         -0.1204 |

So predicted runs ≈ the script's expected runs pulled toward the closing total (`l_tl`) and the moneyline-implied strength, then the NB grid turns the two means into a full score distribution.
