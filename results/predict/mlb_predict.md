# MLB game predictor: winner + final score

Generated by `python -m engine.predict.mlb` (11.2 min). Strict walk-forward: every month from 2018 the models are refit on all games dated before that month (2016 onward) and predict the month. Model picked on 2018-2020 log loss; numbers reported for 2021+ (14,790 games) were never used to pick anything.

* Seasons 2016-2026 (2026 results from the live feed; closing prices only for Sep 14-Oct 14 2026, 210 games).
* Integrity note (results/KEYS.md): MLB 2021+ 'closing' prices failed a steam-move integrity check, so they may be closer to openers / stale quotes than true closes. They are still a pre-game number, so they are used as a feature after odds-ratio de-vig; clearly broken quotes are dropped (rule below). The model-vs-market comparison for 2021+ is against these prices.
* Run line: data has the ±1.5 side but no run-line prices, so break-even uses typical prices (-1.5 at +140, +1.5 at -160).
* Market: closing moneyline de-vigged with `engine.devig.devig(a, b, 'odds_ratio')`. Quotes dropped as broken: missing, |odds|<100, overround outside 0.995-1.12, or de-vigged price >30 pts away from the script (26 dropped for disagreement in the predicted seasons). Games without a usable price fall back to the script (flag `has_mkt`=0).

## 5. The formula (plain English)

Win model **market**. Logistic part (full-data fit), intercept -0.057; terms per one standard deviation and per raw unit:

| feature      |   coef_per_SD |   coef_raw_unit |     SD |
|:-------------|--------------:|----------------:|-------:|
| sim_logit    |        0.2398 |          0.4797 | 0.4998 |
| mkt_gap      |        0.1226 |          0.6043 | 0.2029 |
| rls_home     |       -0.0864 |         -0.3103 | 0.2783 |
| mkt_logit    |        0.0851 |          0.2063 | 0.4127 |
| rls_away     |        0.0794 |          0.2825 | 0.2812 |
| a_opp_sp_k   |        0.0619 |          0.1915 | 0.3233 |
| h_opp_sp_k   |       -0.0534 |         -0.1660 | 0.3215 |
| sp_away_ln   |        0.0435 |          0.0320 | 1.3584 |
| core_diff    |        0.0366 |          0.0539 | 0.6792 |
| a_opp_sp_new |       -0.0306 |         -0.1413 | 0.2167 |
| s_logit      |        0.0291 |          0.0824 | 0.3529 |
| h_opp_sp_sc  |       -0.0250 |         -0.1124 | 0.2226 |
| margin       |       -0.0232 |         -0.0247 | 0.9365 |
| park_ln      |        0.0231 |          0.0430 | 0.5378 |

In words: logit P(home wins) ≈ +0.480×sim_logit + +0.604×mkt_gap + -0.310×rls_home + +0.206×mkt_logit + +0.282×rls_away + (smaller terms) -0.057. `mkt_logit` = log-odds of the de-vigged closing moneyline, `s_logit` = script log-odds.

Score means (Poisson GLM, log link): log E[home runs] and log E[away runs] = intercept + Σ coef×feature, largest terms:

So predicted runs ≈ the script's expected runs pulled toward the closing total (`l_tl`) and the moneyline-implied strength, then the NB grid turns the two means into a full score distribution.
